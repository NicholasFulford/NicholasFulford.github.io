This project is being carried out in parallel with 'Characterising Regime Change In Financial Markets', with both projects applying the ideas of persistent homology and topological data analysis. 

This project aims to quantify the topological variations between clean and adversarial activations within LLMs, building upon the foundational framework established by <a href='https://arxiv.org/pdf/2505.20435'>Fay et al. (2025)</a> regarding "topological compression" in latent spaces.
